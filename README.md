# ペーパーフィルムジェネレーター（Paper Film Generator）

ペーパーフィルム（紙に描いて映写・スキャンするアニメーション）用の作画用紙を作るWebアプリ。
実際のフィルム規格（8mm・スーパー8・16mm・35mm など）の実寸で、用紙（A5〜A3）にスキャン用トンボ付きで並べる。

公開版：https://t1912-hub.github.io/PaperFilmGenerator/

表示言語は日本語・English・한국어 を右上で切り替えられる（`?lang=en` / `?lang=ko` でも指定可）。

## スキャン → 動画

印刷した用紙に描いてスキャンした画像から、トンボで位置を合わせてコマを切り出し、動画にする。
https://t1912-hub.github.io/PaperFilmGenerator/scan.html （日本語のみ）
